# RunsOnVibes / plans

A tiny archive of plans.

## Structure

- `index.html` — plans landing page
- `july-3-plan/` — original July 3 plan, including its assets
- `aug-22-plan/` — August 22 Connecticut driving plan

## Publish with GitHub Pages

1. Upload the **contents** of this folder to the `plans` repository (not the ZIP itself).
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing these files (usually `main`) and the `/ (root)` folder.
5. Save.

The site should then be available at the GitHub Pages URL for the repository.

## Privacy note

The August plan deliberately uses the public Grove Street area rather than a home address.
